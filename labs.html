Лабораторна робота №9: OpenCV (обробка зображень)

Завдання

Реалізувати розмиття (blur) та підвищення різкості (sharpen) зображення.

Код sharpen

import cv2
import numpy as np

img = cv2.imread('input.jpg')
kernel = np.array([[0, -1, 0],
                   [-1, 5, -1],
                   [0, -1, 0]])
sharp = cv2.filter2D(img, -1, kernel)
cv2.imwrite('sharpened.jpg', sharp)

Лабораторна робота №10: Паралелізм (threading vs multiprocessing)

Мета

Порівняти продуктивність послідовної, багатопотокової та багатопроцесорної обробки зображень.

Теоретичні відомості

Потоки (threading) в Python обмежені GIL (Global Interpreter Lock), тому для CPU-інтенсивних задач вони не дають прискорення. Процеси (multiprocessing) створюють окремі інтерпретатори з власним GIL, що дозволяє реально використовувати кілька ядер процесора.

Висновки

  • Потоки не прискорюють обчислювальні задачі через GIL.
  • Процеси дають прискорення, пропорційне кількості ядер.
  • Для I/O-задач потоки можуть бути ефективними через менші накладні витрати.

Приклад коду

from multiprocessing import Pool

def process_image(path):
    img = cv2.imread(path)
    # обробка...

with Pool(4) as pool:
    pool.map(process_image, image_paths)

Лабораторна робота №11: Мережеве програмування (TCP-сокети)

Мета

Реалізувати клієнт-серверну взаємодію через TCP-сокети з обміном JSON-запитами.

Опис роботи

Сервер очікує з’єднання на порту 25002, приймає JSON-запити двох типів: fetch (завантаження веб-сторінки з поверненням заголовків та рядків за регулярним виразом) та bw_image (завантаження зображення, перетворення на чорно-біле та відправка байтів). Клієнт надсилає запити та виводить відповідь (для fetch – JSON, для bw_image – зберігає зображення).

Основні технології

  • Сокети (socket)
  • Серіалізація JSON
  • HTTP-запити через requests
  • Обробка зображень (OpenCV)

Висновки

Створено робочу клієнт-серверну систему, яка демонструє базові принципи мережевого програмування, обмін структурованими даними та передачу бінарних файлів.

Лабораторна робота №12: DuckDB + великі дані Wikipedia

Мета

Інтегрувати DuckDB у серверну частину для аналізу великих даних Wikipedia (перегляди сторінок).

Конвертація даних

Вхідний BZ2-файл (дані переглядів Wikipedia) перетворюється у формат Parquet з фільтрацією англійських статей.

import duckdb, bz2, shutil

def ingest(bz2_path, parquet_path):
    csv_path = bz2_path.replace('.bz2', '.csv')
    with bz2.open(bz2_path, 'rb') as f_in, open(csv_path, 'wb') as f_out:
        shutil.copyfileobj(f_in, f_out)
    con = duckdb.connect()
    con.sql(f"""
        COPY (
            SELECT wiki_code, article_title, view_count, hourly_encoded
            FROM read_csv('{csv_path}', delim=' ', header=false,
                columns={{'wiki_code':'VARCHAR','article_title':'VARCHAR',
                          'page_id':'VARCHAR','agent_type':'VARCHAR',
                          'view_count':'INTEGER','hourly_encoded':'VARCHAR'}})
            WHERE wiki_code IN ('en.wikipedia','en.wikipedia.m')
              AND article_title NOT LIKE 'Special:%'
        ) TO '{parquet_path}' (FORMAT PARQUET)
    """)
    os.remove(csv_path)

Лабораторна робота №13: FastAPI (заміна сокетів на HTTP)

Мета

Замінити TCP-сокетний сервер на FastAPI для реалізації REST API.

Ендпоінти

  • POST /fetch – отримання заголовків та рядків за regex.
  • POST /bw-image – чорно-біле зображення.
  • GET /stats/top – топ статей (DuckDB).
  • GET /stats/agents – розподіл за агентами.
  • GET /stats/hourly – погодинна статистика.

Приклад клієнта на requests

import requests
resp = requests.get("http://localhost:8000/stats/top", params={"limit": 5})
print(resp.json())

Переваги FastAPI

  • Автоматична документація (/docs)
  • Асинхронність
  • Валідація через Pydantic
